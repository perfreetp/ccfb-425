# eVTOL 起降点净空分析系统（OLS Studio）

面向城区楼顶 vertiport 选址的三维净空校核工具：在浏览器里放置起降平台、自动生成障碍物限制面（OLS）、导入城区楼块与塔吊、自动计算穿透高度并导出 PDF 报告。纯前端实现，TypeScript + Three.js，数据保存在浏览器本地，无需后端。

## 功能与需求对应

| # | 需求 | 实现 |
|---|------|------|
| 1 | 项目新建/复制/删除、浏览器存储、导入导出 | `src/store.ts`（localStorage 持久化 + JSON 导入导出），项目列表页 |
| 2 | 楼顶平台、FATO 尺寸、进近方向、自动生成三类限制面 | `src/lib/ols.ts` 按坡度生成进近面、起飞爬升面、过渡面（另含水平限制面） |
| 3 | 限制面半透明曲面 + 线框切换 | `Scene3D` 半透明双面材质，工具栏「线框」开关 |
| 4 | GeoJSON 楼块拉伸 + 手点临时塔吊 | `src/lib/geojson.ts`（经纬度自动投影），障碍物库页支持点选放置与参数化塔吊 |
| 5 | 穿透部分标红 + 穿透高度 | `src/lib/analysis.ts` 网格扫描/沿线采样，红色穿透盒与球面标记，输出最大穿透高度与坐标 |
| 6 | 拖动/旋转后 1 秒内刷新 | TransformControls 拖拽，250ms 防抖重算；演示场址实测约 2–10ms |
| 7 | 日照 / 夜间灯光 | 两套光照主题，夜间含楼顶红色航空障碍灯与暖色点光源，选择随项目持久化 |
| 8 | 带截图和穿透清单的 PDF | html2canvas 思路下直接用 WebGL `toDataURL` 截图 + jsPDF 生成多页报告 |

## 五个页面

1. **项目列表**：项目卡片、新建、复制、删除、单个/批量 JSON 导入导出，卡片上直接显示净空是否合格。
2. **场址编辑**：平台坐标/标高、FATO 长宽、安全区、进近方位角，以及四类限制面的长度/坡度/顶盖参数；三维视图中可平移、旋转平台。
3. **障碍物库**：GeoJSON 导入（Polygon/MultiPolygon，识别 `height`/`高度` 等字段）、添加塔吊、点选放置、楼高/塔吊参数编辑、宿主楼指定（宿主楼豁免穿透判断）。
4. **净空分析**：统计卡片、按限制面类型筛选的穿透清单（障碍物、穿透面、穿透高度、限制面标高、最大穿透点坐标），红色穿透体可视化。
5. **报告**：捕获三维截图、填写备注、一键导出含概况/截图/限制面参数/穿透清单/PASS-FAIL 结论的 PDF。

## 净空模型说明

- 世界坐标系为 ENU（x 东、y 北、z 绝对标高，单位米）；局部坐标 u 沿进近方向、v 横向。
- 进近/起飞面为带侧向扩散（每 8m 水平距离外扩 1m）的梯形斜面，坡度以 `水平:垂直` 表达（如 8 = 1:8），可在编辑页调整。
- 过渡面自进近/起飞面侧边按独立坡度抬升，至水平顶盖高度截止；顶盖为以平台为圆心的圆形水平限制面。
- 任一点的限制面标高取适用面的**最低值**（最严格约束）。
- 楼块采用自适应步长网格扫描（约 60 格），相邻穿透格合并为长方体穿透盒；塔吊对塔身与起重臂沿线采样。

默认参数为演示取值，正式选址请按当地民航/行业规范（如 vertiport 设计指南）在编辑页校核调整。

## 目录结构

```
src/
  types.ts            全部数据类型
  store.ts            localStorage 项目仓储(增删复制/导入导出)
  lib/
    ols.ts            限制面数学模型(坐标变换/标高查询/曲面描述)
    analysis.ts       穿透分析引擎(网格扫描/采样/盒合并)
    geometry.ts       二维多边形几何(射线法/裁剪/相交)
    geojson.ts        GeoJSON 解析与经纬度投影
    pdf.ts            jsPDF 报告生成
    demo.ts           演示城区数据
  three/Scene3D.ts    Three.js 场景(渲染/拾取/拖拽/日夜主题)
  ui/                 五个页面与应用框架
```

## 数据格式（导入导出）

项目 JSON 即 `Project` 结构的完整序列化（见 `src/types.ts`），包含 `platform`、`obstacles` 等字段；支持单项目对象或项目数组。GeoJSON 示例见 `public/demo-buildings.geojson`。
